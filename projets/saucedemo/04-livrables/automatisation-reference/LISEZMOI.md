# Scripts Playwright de référence (démonstration)

Recopiés par le faux modèle (`saas/dev/faux_modele.py`) pour la commande /automatiser, et utilisés par les tests
du SaaS. Ils ne viennent pas d'une vraie génération : ce sont des exemples écrits à la main pour SauceDemo,
avec les attributs `data-test` de l'application. `depot/` est recopié dans le dépôt d'automatisation du projet,
`resultats/` dans le dossier de la génération.
